# 🛒 Shopping System Cart

A simple **Shopping Cart System built with Python**. This beginner-friendly project allows users to add products and prices to a cart, view the cart, remove products, and calculate the total bill.

## 📌 Features

* ➕ Add products to the cart
* 👀 View all products in the cart
* ❌ Remove a product from the cart
* 🧾 Calculate the total bill
* 🚪 Exit the program
* 💻 Simple command-line interface

## 🛠️ Technologies Used

* **Python 3**
* Python functions
* Lists
* `input()` and `print()`
* Conditional statements
* Loops

## ▶️ How to Run

1. Make sure Python 3 is installed on your computer.
2. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

3. Open the project folder:

```bash
cd YOUR_PROJECT_FOLDER
```

4. Run the Python file:

```bash
python shopping_system.py
```

## 🎮 How to Use

When you run the program, you will see the following menu:

```text
===== Shopping System Cart =====
1. Add Product
2. View Cart
3. Remove Product
4. Bill
5. Exit
```

Enter the number corresponding to the action you want to perform.

### Example

To add products, choose option `1` and enter the product names and prices separated by commas.

```text
Enter your product name: Apple, Milk, Bread
Enter the product prices: 100, 250, 150
```

The products will then be added to the shopping cart.
